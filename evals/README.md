# 행동 eval

`cases.yaml`은 모델이 특정 문장을 출력하는지 검사하는 스냅샷 테스트가 아니다. 사용자가 어떤 말을 했을 때 필요한 행동과 금지 행동을 확인하는 계약이다.

## 평가 방법

각 사례를 새 Codex 대화에서 실행하거나, 실제 Skill을 사용하는 수동 평가자에게 제시한다.

1. 입력을 그대로 보낸다.
2. 첫 응답이 개입·비개입 규칙에 맞는지 확인한다.
3. 사용자가 동의하거나 답을 준 다음 단계의 행동을 확인한다.
4. `must`와 `must_not`를 각각 기록한다.
5. 문장 표현이 달라도 의미와 행동이 계약에 맞으면 통과시킨다.

## 판정

- `PASS`: 모든 필수 행동과 금지 행동을 확인
- `FAIL`: 필수 행동 누락 또는 금지 행동 발생
- `NOT RUN`: 실제 대화를 실행하지 않음
- `BLOCKED`: 환경·권한·외부 조건 때문에 평가할 수 없음

문서 구조 검증은 `validate_spec.py`, 설치·파일 상태 점검은 `doctor.py`가 담당한다. 두 스크립트의 PASS가 행동 eval PASS를 대신하지 않는다.
