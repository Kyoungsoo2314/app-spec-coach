# 예제: 민감한 상담 기록 업무 앱

이 예제는 실제 개인정보를 사용하지 않는 가상 사례다. 민감 데이터가 포함될 수 있는 다중 사용자 앱에서 인터뷰 깊이를 높이는 방법을 보여준다.

## 한 문장

이 앱은 승인된 직원이 상담 업무의 다음 처리 상태를 확인하고 필요한 내부 기록을 안전한 범위에서 이어서 작성하도록 돕는다.

## 먼저 확인할 것

- 어떤 사람이 어떤 기록을 볼 수 있는가?
- 상담 기록 중 꼭 필요한 정보와 수집하면 안 되는 정보는 무엇인가?
- 기록을 수정하거나 삭제할 수 있는 사람은 누구인가?
- 퇴사·이동한 직원의 접근은 어떻게 중단하는가?
- 기록 보관 기간과 복구 요구는 무엇인가?
- 실제 데이터 없이 테스트하는 방법은 무엇인가?
- 내부 네트워크만 쓸지 외부 접근이 필요한가?

## 보호 기준

- 예제·스크린샷·로그에 식별정보를 넣지 않는다.
- 최소한의 정보만 수집한다.
- 사용자별 접근 범위를 명시한다.
- 백업과 복구를 실제 운영 조건으로 확인한다.
- 실제 운영 전 보안·법률·기관 정책 검토가 필요함을 기록한다.

## 비목표

- 법률·규정 준수 자동 보장
- 진단·치료 판단 자동화
- 공개 인터넷에 바로 노출
- 실제 식별정보를 포함한 데모
