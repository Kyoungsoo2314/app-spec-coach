# 예제: 개인용 운동 기록 도구

이 예제는 한 사람이 자기 기기에서 쓰는 작은 도구다. 처음부터 로그인·다중 사용자·서버를 강제하지 않는 사례로 사용한다.

## 한 문장

이 도구는 한 사람이 운동 후 내용을 빠르게 기록하고 지난 기록과 다음 운동 계획을 확인하는 도구다.

## 핵심 흐름

```text
운동을 마침
→ 날짜·운동 종류·시간·메모 입력
→ 저장
→ 최근 기록 확인
→ 지난 기록을 참고해 다음 운동 계획
```

## MVP

- 운동 기록 입력
- 최근 기록 목록
- 기록 수정
- 기록 삭제 전 확인
- 새로고침 후에도 기록 유지

## 비목표

- 다른 사람과 공유
- 전문 건강 진단
- 자동 코칭 판정
- 외부 웨어러블 연동

## 확인할 질문

- 기록은 오프라인에서도 필요한가?
- 운동 종류는 자유 입력인가, 자주 쓰는 선택지인가?
- 삭제한 기록을 복구해야 하는가?
- 한 기기에서만 사용하는가?

## 성공 기준

운동 후 1분 안에 기록을 저장하고, 다음에 앱을 다시 열었을 때 지난 기록을 찾을 수 있다.
